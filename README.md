# ⚽ Portfólio Neymar Jr.

Um projeto front-end de um site fictício desenvolvido como se a equipe tivesse sido contratada para criar a página oficial de portfólio do jogador Neymar Jr. O site apresenta a trajetória do atleta, suas conquistas, o Instituto Neymar Jr., novidades recentes e redes sociais.

*Projeto acadêmico desenvolvido no 1º período do curso de Ciência da Computação na Universidade Veiga de Almeida (UVA), entre março e abril de 2023.*

## 🚀 Funcionalidades

* **Navegação Multipáginas:** Estrutura dividida em cinco seções (Apresentação, Novidades, Portfólio, Detalhes e Contato) para facilitar a leitura.
* **Efeito Parallax:** Implementação de rolagem com profundidade nas imagens de fundo utilizando CSS puro.
* **Animações Dinâmicas:** Elementos e textos surgem na tela de forma interativa conforme o scroll do usuário.
* **Hub de Contatos:** Links integrados direto para as plataformas oficiais do jogador (Twitch, Instagram, Twitter, YouTube e Steam).

## 🛠️ Tecnologias Utilizadas

As seguintes ferramentas foram usadas na construção do projeto:

* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização geral e criação do efeito *parallax* com gradientes.
* **JavaScript (Vanilla):** Lógica simples de roteamento entre as páginas.
* **[ScrollReveal.js](https://scrollrevealjs.org/):** Biblioteca externa utilizada para revelar elementos no momento do scroll (eixos X, Y e Z).
* **Google Fonts:** Utilização das tipografias *Changa One* e *Merriweather Sans*.

## ⚙️ Como executar o projeto

Por se tratar de um site estático, a execução é bem simples e não exige a instalação de servidores locais ou dependências complexas.

1. Clone este repositório:
`git clone https://github.com/seu-usuario/nome-do-repositorio.git`

2. Acesse a pasta do projeto:
`cd nome-do-projeto`

3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência (Chrome, Firefox, Edge, etc.).
